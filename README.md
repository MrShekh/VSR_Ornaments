# VSR Atelier

Production-ready editorial fine-jewellery website built with Next.js, TypeScript, Tailwind CSS, GSAP ScrollTrigger, Lenis and Framer Motion.

## Run locally

```bash
pnpm install
pnpm dev
```

Use `pnpm build` for the optimized production build.

## Routes

- `/` — editorial homepage
- `/collections` — catalogue and filters
- `/product/[slug]` — immersive product detail pages
- `/bespoke`, `/craftsmanship`, `/about` — house stories
- `/search`, `/wishlist`, `/contact` — utility experiences

Campaign photography in `public/images` was generated specifically for this project. Design observations and reusable tokens are documented in `DESIGN_SYSTEM.md`.
